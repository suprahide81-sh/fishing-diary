# 🎣 釣り日記（FISHING LOG）

話すだけで釣行を記録できるスマホ向けWebアプリ。
アプリを差し込める作りになっていて、「釣り日記」と「動画」が同じデータを共有します。

## できること

- **音声／テキスト入力** → 内容に合わせて自動で振り分け
  - 「場所は○○ダム、晴れ、気温18度、北風」→ データ（釣り場・天候・気温・風・水・ルアー）
  - 「42センチのバス、スピナーベイトで釣れた」「3匹釣れた」→ 釣果
  - 「メモ 風裏のワンドに移動」→ メモ
- **自然な文章に整える音声入力**
  - 「晴れです晴れです」「バス バス バス」のような重複をまとめる
  - 「えーと」「あー」などの言いよどみを除く
  - 単語の間に入る余計な空白を消す（「42 センチ の バス」→「42センチのバス」）
  - 少しずつ伸びて届く認識結果を1つの文につなげる
  - 「三匹」→3匹、「3引き」→3匹 などの誤変換を直す
  - よく間違う言葉は「まとめ」タブの **言い換え辞書** に登録すると自動で直る
  - メモは文末に句点をつけて文章らしく保存
- **釣行ごとに自動保存**（端末内 localStorage）。ヘッダーの日付から過去の釣行に切り替え・新規作成
- 釣果・メモの編集／削除、まとめ、通算記録（総釣果・自己最大・よく釣れたルアー）
- テキスト書き出し、全データのバックアップ（JSON）と復元
- 動画：撮影・取り込み → 釣果にひも付けて保存（端末内 IndexedDB）
- テーマ3種（ライト／ダーク／和風）、ホーム画面に追加してオフライン利用（PWA）

## 使い方

GitHub Pages などで公開して、スマホのブラウザ（Chrome / Safari）で開きます。
音声入力は https で開いたときに使えます。

ローカルで試す場合:

```sh
python3 -m http.server 8000
# → http://localhost:8000
```

## ファイル構成

```
index.html            画面の骨組み。アプリの <script> を並べる
css/app.css           見た目（テーマ含む）
js/core/util.js       共通ユーティリティ・イベントバス
js/core/store.js      データ保存（釣行・釣果・メモ・メディア情報）
js/core/media.js      動画・写真の本体保存（IndexedDB）
js/core/speech.js     音声入力と文章の整形
js/core/parser.js     話した内容から釣りデータを取り出す
js/core/apps.js       アプリ登録・ナビ・共通UI
js/apps/diary.js      釣り日記アプリ
js/apps/video.js      動画アプリ（土台）
docs/ADD_APP.md       新しいアプリの組み込み方
```

## 動画アプリを作るとき

[docs/ADD_APP.md](docs/ADD_APP.md) を見てください。
`js/apps/video.js` を作り替えるか、新しいファイルを作って `index.html` に1行足すだけで下のナビに追加されます。
