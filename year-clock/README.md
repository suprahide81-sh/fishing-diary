# 1年の秒時計

今年が始まってから何秒たったか（または、あと何秒で終わるか）を大きく表示する時計です。
1つのHTMLファイルで動き、ホーム画面に追加すればアプリのように使えます（PWA）。

## 機能

- **経過した秒 / 残りの秒** の切り替え（選んだほうを覚えておく）
- 「つまり 302日 3時間 51分 45秒」のように、日・時間・分にも言いかえて表示
- **今年の進み具合**：％表示と、月ごとの日数どおりの幅で目盛りを付けたバー
- **今日の秒**：0〜86,400秒のうち今どこか
- **次の節目**：100万秒ごとの節目に何月何日何時何分に着くか。通過するとお知らせ
- **大切な日まで**：誕生日などを入れると、その日までの秒数を表示（毎年くり返しも可）
- **画面を消さない**：置き時計として使うときにスリープを防ぐ（対応ブラウザのみ）
- **大きく表示**：数字とバーだけの置き時計モード
- うるう年（366日 = 31,622,400秒）に自動で対応、ダークモード対応、オフラインでも動作

## ファイル

| ファイル | 役割 |
| --- | --- |
| `index.html` | アプリ本体（HTML・CSS・JavaScriptを1つにまとめたもの） |
| `manifest.webmanifest` | アプリ名・アイコン・色など（ホーム画面追加とGoogle Play用） |
| `sw.js` | オフラインで開くためのサービスワーカー |
| `icons/` | アプリのアイコン（通常用・Androidのマスカブル用・iPhone用） |
| `privacy.html` | プライバシーポリシー（Google Playの掲載に必要） |

## Google Play で公開するまで

1. **専用のリポジトリに分けて、HTTPSで公開する**
   GitHub Pages などで公開します。TWA（下記）を使う場合は、ドメインの一番上に
   `/.well-known/assetlinks.json` を置く必要があるため、`ユーザー名.github.io` リポジトリか独自ドメインが必要です。
2. **Androidアプリにまとめる**（どちらかを選ぶ）
   - **TWA（Trusted Web Activity）**：[PWABuilder](https://www.pwabuilder.com/) か Bubblewrap に公開URLを入れると、Google Play 用のファイル（.aab）ができます。いちばん手軽です。
   - **Capacitor**：この `index.html` をそのまま中に入れてネイティブアプリにします。AdMob広告、ホーム画面ウィジェット、通知など、収益化や追加機能に向いています。
3. **Google Play Console に登録する**（登録料 25ドル・1回のみ）
   新しい個人アカウントでは、本番公開の前に **12人以上のテスターで14日間のクローズドテスト** が必要です。
4. ストア掲載情報（説明文、スクリーンショット、`privacy.html` のURL、データセーフティの回答）を入れて審査に出します。
   このアプリは個人情報を集めず、設定は端末内にだけ保存しています。
