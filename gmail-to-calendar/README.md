# Gmail予約完了メール → Googleカレンダー自動登録

Gmailに届いた予約完了・予約確認メールを30分おきに自動チェックし、本文から日時・内容を読み取ってGoogleカレンダーに予定を登録するGoogle Apps Script(GAS)です。

サーバー不要・無料で動作し、権限はすべて自分のGoogleアカウント内で完結します。

## できること

- 予約メールの検出(件名・本文の「予約完了」「ご予約ありがとうございます」等のキーワード)
- 本文から **日時・所要時間・メニュー・店名・住所** を読み取ってカレンダーに登録
- 処理済みメールにはGmailラベル「カレンダー登録済」を付けて二重登録を防止
- フェリー等の往路・復路は**区間ごとに別々の予定**として登録
- 予約**変更**メール(申込番号付き)では、旧予定を削除して新しい日時で登録し直し
- 予約**キャンセル**メールを検出したら、対応するカレンダーの予定を自動削除

### 対応しているメール形式

| 形式 | 例 | 登録される予定 |
|---|---|---|
| サロン系(ホットペッパー等) | `【予約日時】 9/5(土) 12:30`+`【所要時間】 120分` | 💇 STOKED カラーエステ＋カット (12:30〜14:30) |
| フェリー・交通系 | `2026/09/19(土)` `17:15発 20:50着` `青森→函館` | 🚢 青森→函館 (17:15〜20:50) |
| 汎用 | 「予約日時」「ご利用日」等の近くにある日付+時刻 | 📅 (メール件名) |

年の書かれていない日付(`9/5`など)は、メール受信日以降で最初に来る日付として解釈します(年末に翌年の予約をしてもOK)。

### キャンセルメールの扱い

件名の「予約キャンセル」「予約取消」や、本文の「キャンセルを承りました」「取消が完了しました」等の**完了表現**を検出すると、対応する予定を削除します。

- 申込番号・予約番号があるメール(フェリー等) → その番号で登録した予定を削除
- 番号がないメール(サロン等) → 本文の日時と同じ開始時刻の予定を削除

誤って手動の予定を消さないよう、**削除対象はこのスクリプトが作成した予定(説明欄に「自動登録」の目印があるもの)だけ**です。予約確認メールの注意書き(「変更・キャンセルはお電話にて」等)には反応しないようになっています。

## セットアップ手順(5分)

1. [script.google.com](https://script.google.com) を開き、「新しいプロジェクト」を作成
2. エディタに `Code.gs` の内容を貼り付けて保存(プロジェクト名は「予約メール→カレンダー」など)
3. 左メニュー「プロジェクトの設定」→ タイムゾーンが **東京** になっているか確認(`appsscript.json` を表示して編集してもOK)
4. 関数の選択で **`syncBookingMailsToCalendar`** を選んで一度「実行」
   - 初回はGmail・カレンダーへのアクセス許可を求められるので承認する
   - これで直近7日分の予約メールが処理される
5. 関数の選択で **`setupTrigger`** を選んで「実行」
   - 以降、30分おきに自動でチェックされます

## カスタマイズ

`Code.gs` 冒頭の `CONFIG` を編集します。

```js
const CONFIG = {
  calendarId: 'primary',            // 予定を入れるカレンダー(別カレンダーはIDを指定)
  searchQuery: '{予約完了 ...} newer_than:7d', // 検出キーワード
  processedLabel: 'カレンダー登録済',  // 処理済みラベル名
  defaultDurationMinutes: 60,       // 所要時間不明時の予定の長さ(分)
};
```

- **釣り船の予約サイトなど、検出したい送信元を追加したい場合**: `searchQuery` に `from:xxx@example.com` をOR条件で足すのが確実です。
  例: `'{予約完了 予約確定 from:yoyaku@tsuribune.example.jp} newer_than:7d'`
- 実行間隔を変えたい場合は `setupTrigger` 内の `everyMinutes(30)` を変更(1, 5, 10, 15, 30が指定可)

## 動作の仕組み

1. Gmailを `searchQuery` で検索(処理済みラベルが付いたスレッドは除外)
2. キャンセルメールなら対応する自動登録済みの予定を削除
3. それ以外は最新メッセージ本文を3種類のパーサー(フェリー系→サロン系→汎用)の順で解析
4. 読み取れた予約ごとにカレンダーへ予定を作成(同タイトル・同時刻の予定があればスキップ)
5. 予約情報が読み取れなかったメール(お知らせ・広告等)もラベルを付けて次回以降はスキップ

## 制限事項

- HTMLメールのみで平文パートがないメールは解析できないことがあります
- 申込番号も日時も書かれていないキャンセルメール(「ご予約をキャンセルしました」のみ等)は、どの予定か特定できないため自動削除できません。その場合は手動で削除してください
- Gmail検索の仕様上、キーワードに一致した広告メール等も走査対象になりますが、日時が読み取れなければ登録はされません
