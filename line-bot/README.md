# LINE予定登録ボット → Googleカレンダー

友だちとのLINEで決まった予定(「9/20 10時に港集合ね」等)を、ボットに**転送するだけ**でGoogleカレンダーに登録するボットです。登録できたらLINEに確認の返事が返ってきます。

LINEの仕様上、個人トークを外から自動で読み取ることはできないため、「転送」のひと手間だけは必要です。グループトークにボットを招待すれば、日時を含む発言を転送なしで自動登録することもできます。

## 対応している日時表現

| 種類 | 例 |
|---|---|
| 日付 | `9/20`、`9月20日`、`2026/9/20`、`今日`、`明日`、`明後日`、`土曜`、`来週土曜`、`再来週金曜` |
| 時刻 | `10:00`、`10時`、`10時半`、`10時15分`、`午後7時`、`夜8時` |

- 時刻がなければ**終日予定**として登録
- 年のない日付は今日以降で最初に来る日付として解釈

## 予定タイトルの付き方

メッセージ全文ではなく、**何の予定かを表す短いタイトル**が付きます。2段構えです。

1. **キーワード辞書方式(標準・設定不要)** — メッセージ内の「釣り」「飲み会」「ゴルフ」「歯医者」などのキーワードを探してタイトルにします。対象の語は `Code.gs` 冒頭の `TITLE_KEYWORDS` で自由に追加・変更できます。どれにも当てはまらない場合は、日時を除いた残りの文(15文字まで)を使います。
2. **AI方式(任意)** — Googleの生成AI「Gemini」の**無料APIキー**を設定すると、AIがメッセージを読んで「田中さんとランチ」のような自然なタイトルを付けます。設定方法:
   1. [Google AI Studio](https://aistudio.google.com/apikey) を開き、Googleアカウントでログイン →「APIキーを作成」
   2. `Code.gs` 冒頭の `const GEMINI_API_KEY = '';` の `''` の中にキーを貼って保存
   3. 「デプロイ」→「デプロイを管理」→ 鉛筆アイコン →「新バージョン」→「デプロイ」で反映

   AIの呼び出しに失敗した場合は自動でキーワード辞書方式に切り替わるので、予定登録自体が失敗することはありません。個人利用ならGeminiの無料枠で十分収まります。

   ※参考: Claude API(Anthropic)でも同様のことができますが、無料枠がなくクレジットカード登録が必要なため、このボットでは無料枠のあるGeminiを採用しています。

## セットアップ手順(15分ほど)

Gmail連携より少し手順が多いですが、一度やれば終わりです。大きく「LINE側でボットを作る」→「GAS側でコードを動かす」→「両者をつなぐ」の3段階です。

### 1. LINE側: ボット(Messaging APIチャネル)を作る

1. [LINE Developersコンソール](https://developers.line.biz/console/) を開き、普段のLINEアカウントでログイン
2. 「プロバイダー」を新規作成(名前は「個人用」など何でもOK)
3. 「Messaging API」のチャネルを作成
   - チャネル名: 「予定登録ボット」など(これがボットのLINE上の名前になります)
   - 業種などは適当でOK
   - ※途中でLINE公式アカウント(無料)の作成に誘導された場合はそのまま作成してください
4. 作成したチャネルの「**Messaging API設定**」タブを開き、一番下の「**チャネルアクセストークン(長期)**」の「発行」を押して、表示された長い文字列をコピーしておく

### 2. GAS側: コードを動かす

1. [script.google.com](https://script.google.com) で「新しいプロジェクト」を作成(Gmail連携とは**別プロジェクト**にする)
2. `Code.gs` の中身を貼り付ける
3. 冒頭の `const LINE_CHANNEL_ACCESS_TOKEN = 'ここにチャネルアクセストークンを貼る';` の部分に、手順1-4でコピーしたトークンを貼り付けて保存
4. 右上の「**デプロイ**」→「**新しいデプロイ**」→ 歯車アイコンで種類「**ウェブアプリ**」を選択
   - 「次のユーザーとして実行」: **自分**
   - 「アクセスできるユーザー」: **全員**
5. 「デプロイ」を押す → 初回はGmail連携のときと同じ権限許可の画面が出るので許可する
6. 表示された「**ウェブアプリのURL**」(https://script.google.com/macros/s/…/exec)をコピー

### 3. つなぐ

1. LINE Developersの「Messaging API設定」タブに戻り、「**Webhook URL**」に手順2-6のURLを貼って「更新」→「検証」で成功と出ればOK
2. すぐ下の「**Webhookの利用**」をONにする
3. 同じ画面の「応答メッセージ」の「編集」を押すと LINE Official Account Manager が開くので、**応答メッセージをOFF**にする(ONのままだと定型文が二重に返ってきます)
4. 「Messaging API設定」タブ上部のQRコードを自分のLINEで読み取り、ボットを**友だち追加**

## 使い方

- 友だちとのトークで予定のメッセージを**長押し→転送**→ボットを選ぶ
- または、ボットとのトークに直接「9/20 10:00 釣り」のように入力
- 「📅 カレンダーに登録しました」と返事が来たら完了
- グループで使う場合: LINE Developersの「Messaging API設定」で「グループトーク・複数人トークへの参加を許可する」をONにしてから、グループにボットを招待。日時を含む発言だけに反応します

## 注意点・制限

- **料金は無料**です(返信のみ使用しており、LINEの無料枠の対象外にならない「応答メッセージ」だけで動きます)
- 「◯時間後」「再来月」などの相対表現、時間の範囲(「10時〜15時」は開始10時の1時間予定になる)は未対応です
- コードを修正したときは、保存だけでなく「デプロイ」→「**デプロイを管理**」→ 鉛筆アイコン → バージョン「**新バージョン**」→「デプロイ」としないとLINE側に反映されません(URLは変わりません)
- チャネルアクセストークンは他人に知られないようにしてください(知られるとあなたのボットとしてメッセージを送られてしまいます)
